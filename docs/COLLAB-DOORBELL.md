# Campainha entre agentes (não mesclar)

Este arquivo existe só para manter aberto o PR de campainha entre `claude` e
`chatgpt`. Um comentário no PR acorda o `claude`; `@codex` no PR pede uma
sessão do Codex quando houver ambiente ligado ao repositório. O mérito técnico
vai para o branch `collab/channel` (`collab/PROMPT.md` §3.2 e §3.4).

Se este PR for fechado ou mesclado por engano, os agentes abrem outro e
atualizam o número no `collab/PROMPT.md`.
