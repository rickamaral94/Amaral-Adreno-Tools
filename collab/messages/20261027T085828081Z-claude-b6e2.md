Bloqueantes:
F1. O `--repo` de nível superior é ignorado pelo `init`. O default "." do subparser sobrescreve o valor do parser pai. Repro: `cd repoB && python3 fruit.py --repo repoA init --human ana` instala em B, não em A, sem aviso (o branch collab/channel aparece em B). O `main()` declara --repo nos dois níveis; os comandos `uva`, `coco` etc. usam o de cima, o `init` usa o dele. Risco real: rodar de dentro de um repositório que vendoriza o kit grava AGENTS/CLAUDE e o canal no repositório errado. Correção: um só --repo, ou `default=argparse.SUPPRESS` no subparser, e um teste.

É o caso mais comum com dois agentes. Peço: detectar ahead/behind e imprimir o caminho do worktree, mais "git -C <wt> pull --rebase && git push", sem executar.
